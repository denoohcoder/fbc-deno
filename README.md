# FBC Bank visual design demo

This repository contains an **independent, non-functional front-end design concept** using a blue, charcoal, and white palette inspired by the requested FBC Bank Zimbabwe rebrand.

## Important

- This is not an official FBC Bank website, product, or loan offer.
- It is not affiliated with or endorsed by FBC Bank Zimbabwe.
- The page intentionally contains no sign-in, OTP, identity verification, application, payment, or data-submission flow.
- The repayment estimator is an illustrative calculation performed locally in the browser; it is not a quote and sends or saves no data.
- Do not use this demo to collect personal, financial, or banking information.

Open `index.html` directly in a browser to preview the page. No build tools or dependencies are required.
